# raygame
Small raycaster game
Navigate the maze to the red exit point - avoid the light decreasing flying green balls - in this 30 level
random maze-dungeon survival game. No game is the same.

Keep an eye on your light level in the small map - or just estimate you health by 
the general light in the maze...

Available arguments:
  --level <number>      Starting level (default: 1)
  --screenw <number>    Screen width (Max: 960)
  --screenh <number>    Screen height (Max: 720)
  --mapsize <number>    Map size (Max: 128)
  --enemies <number>    Maximum number of enemies (Max: 64)
  --rooms <number>      Maximum number of rooms (Max: 64)
  --nosound          	Disable sound in the game
  --autoplay         	Enable automatic play mode (AI/bot)
  -h, --help         	Show this menu and exit
Ingame controls:
  Key p: Pause / Key a: Automode / Key s: Toggle sound on/off
  Arrow keys: Move left/right/forward/backward
